# Chaosverse website (GitHub Pages)

A responsive static website for https://www.youtube.com/@enterchaosverse with:
- `index.html` — landing page
- `privacy.html` — privacy policy
- `terms.html` — terms & conditions
- `assets/` — styles and small navigation script

## Publish with GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io` (for a user site), or any repository (for a project site).
2. Upload the contents of this folder to the repository root. Keep `.github/workflows/pages.yml`.
3. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build/deployment source if it is not already selected.
4. Push to the `main` branch. The included workflow deploys the static site.
5. For a project repository, the workflow handles the project path automatically.

## Before publishing

- Review the Privacy Policy and Terms & Conditions. They are starter templates, not legal advice.
- Add a business/contact email and your legal entity/location if appropriate.
- If you add analytics, cookies, forms, embedded YouTube videos, ads, or mailing-list tools, update the Privacy Policy to describe them.
- Replace the copy and colors if you want a different brand direction.

No build step or package installation is required.
